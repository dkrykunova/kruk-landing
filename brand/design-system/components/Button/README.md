Кнопка-капсула для однієї дії: «Записатися», «Отримати знижку», «Записатися через Telegram».

- `kr-btn--primary` (`orange`, текст `ink`) — головна дія на світлому й темному фоні. Одна головна кнопка на екран.
- `kr-btn--butter` (`butter`, текст `ink`) — дія на темному блоці `ink` поруч із `primary` або замість неї (кнопка тарифу Team).
- `kr-btn--telegram` — лише для переходу в Telegram, з іконкою Telegram зліва.
- Текст — дієслово, 1–3 слова. Висота щонайменше 48px; на телефоні кнопка на всю ширину.
- Не робіть білий текст на `orange` і кутасті кнопки.
