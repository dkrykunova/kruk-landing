Мітка-капсула для короткого статусу чи пропозиції.

- `kr-badge--offer` (`lilac`) — пропозиція на світлому фоні: «🎁 Перший місяць зі знижкою до 100%».
- `kr-badge--eyebrow` — надрядкова мітка великими літерами над заголовком: «Скоро в Україні».
- `kr-badge--butter` — мітки на темному `ink`: ролі агентів, бейдж у фінальному блоці.
- До 6 слів. Мітка не клікабельна — для дії є кнопка.
