Мітка-капсула для типу матеріалу, короткого статусу чи анонсу.

- `kr-badge--offer` (`lilac`) — на світлому фоні: тип матеріалу («Порада», «Кейс», «Новина») або анонс «🎁 Два нові матеріали щотижня».
- `kr-badge--eyebrow` — надрядкова мітка великими літерами над заголовком: «Для малого й середнього бізнесу».
- `kr-badge--butter` — мітки на темному `ink`: розділ («AI-агент для соцмереж»), тип головного матеріалу.
- До 6 слів. Мітка не клікабельна — для дії є кнопка.
