Картка тарифу: назва, для кого, стара ціна закреслена, нова ціна `price`, перелік можливостей, кнопка.

- Звичайний тариф — світла картка з кнопкою `primary`; рекомендований (Team) — темна `ink` з кнопкою `butter`.
- Ціна — `1 500 ₴` з нерозривним пробілом; під нею «перший місяць», якщо діє знижка.
- 3–4 пункти можливостей з «✓». Одна рекомендована картка на ряд.
